001_TwoSum
1. Беру первое число (индекс `i`)
2. Проверяю все числа после него (индекс `j`)
3. Если `nums[i] + nums[j] == target` возвращаю индексы `[i, j]`


002_PalindromeNumber.cpp
1. Если число отрицательное сразу false
2. Запоминаем исходное число
3.Переворачиваем число по цифрам (берем последнюю цифру, добавляем в конец, удаляем из исходного)
4. Сравниваем оригинал с перевернутым числом

003_longestCommonPrefix
1. Берёт первое слово.
2. По очереди берёт из него буквы.
3. Проверяет, есть ли такая же буква на том же месте во всех остальных словах.
4. Как только где‑то буква не совпала — возвращает накопленную приставку.
5. Если все буквы подошли — возвращает всю первую строку.
